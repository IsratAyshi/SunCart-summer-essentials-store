
# ☀️ SunCart – Summer Essentials Store

SunCart is a modern summer-themed web application built with Next.js, where users can explore and purchase seasonal curated coastal collections such as sunglasses, summer outfits, skincare products, beach accessories and indulge in the endless summer spirit.

The platform provides a smooth shopping experience with smooth login, register and personalized user profiles.

---

## 🎯 Project Purpose

The purpose of SunCart is to create a responsive and modern seasonal eCommerce platform where users can:

- Browse summer products
- View popular products and summer care tips
- Register/Login
- Manage profile information
- View product details after login

---

## ✨ Key Features

1. BetterAuth Authentication System: Secure Email & Password login and register page, Google social login. Also has protected product details page and user profile page.

2. Product Browsing : Dynamic product listing from JSON server and a sneak peak of popular products section in the home page. Moreover, product details page is available after login, where users can view product details with ratings, stock, and category.

3. User Profile Management: View user profile information, update profile image and name and logout functionality.

4. Modern UI & Responsive Design: Summer-themed Homepage with smooth navigation, banner, promotional marquee, summer care tips section, top brands showcase. Also has fully responsive design for various screen sizes.
